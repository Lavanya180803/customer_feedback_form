# customer_feedback_form
a customer feedback form with various validations.
a. i. Username: Must be atleast 5 characters long and contain only letters
ii. Email: Must be a valid Email format 
iii. Phone number: Must be exact 10 digits long and contain only digits 
iv. Comments: Minimum 20 characters should be typed in the comment text area.
b. add the name of new customers in exsisting list of customers
